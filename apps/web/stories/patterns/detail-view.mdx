# Detail view

Modelled on `/artifacts/[id]` and `/benchmarks/[id]`.

## Structure

`PageHeader` (the item's name as h1, its description, type and version badges, the main action)

> an overview `Card` with the key facts > further cards.

## Rules

1. The name, the key facts and the main action are visible without scrolling at 1440 by 900.
   Source: SPEC-122 prompt (stage 3). The Default story test checks the action.
2. Missing values are said in words ("Not tested yet", "No description in the artifact"),
   never left blank or shown as a dash. Source: AGENTS.md §7, issue 123.
3. An item that does not exist gets a page with the title "… not found", the likely reason and
   a link back to the list. Source: SPEC-122 prompt.
4. Key facts are a description list (`dl`); a DescriptionList primitive is on "What is
   missing", so pages build it by hand today.
5. An item whose source is gone keeps its page: a muted Badge in the header and a `role="note"`
   paragraph under it that says what is kept and how the item comes back. Every section stays
   usable. Source: SPEC-125 §11.2 D9 (a missing artifact on `/artifacts/[id]`).
6. An item found in several places shows each place's version; a place that holds an older one
   gets a muted "older version" Badge. Source: SPEC-126 §11.3 F4, F16 (the Occurrences table on
   `/artifacts/[id]`).
