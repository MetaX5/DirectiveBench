# PageHeader

`import { PageHeader } from '@/components/common'`

## 1. Purpose

The top of every page: the page's h1, one sentence about it, and the page-level actions.

## 2. When to use

Once per page, first in `main`. Every route in `app/` uses it, `PlannedSection` included.

## 3. When not to use

| Situation                       | Use instead           |
| ------------------------------- | --------------------- |
| A section title inside the page | `CardTitle` (h2)      |
| A second header further down    | A card with its title |

## 4. Anatomy

`h1` (`text-page-title`), optional description (`text-body`, `muted-foreground`), optional
actions at the right (`gap-inline`). Bottom spacing `mb-section`.

## 5. Variants

None. Title only; with a description; with actions; with a planned notice in the actions.

<Canvas of={Stories.WithActions} />

## 6. States

No interactive state. Data states: the description falls back to a sentence in words when the
data has none (Detail view pattern); a missing item gets the title "… not found".

<Canvas of={Stories.WithPlannedNotice} />

## 7. Accessibility

- The only h1 on the page; the browser tab title repeats it ("Repositories · DirectiveBench",
  `app/layout.tsx`). Source: WCAG 2.4.2, 1.3.1.
- Actions follow the title in reading and tab order.

## 8. Content

- Title: the page or item name, sentence case; item names as they are (`validate-external-input`).
- Description: one sentence that says what the page holds, under about 90 characters.

## 9. Responsiveness

Title and actions wrap (`flex-wrap`); actions move under the title on narrow screens and
badges wrap inside them.

<Canvas of={Stories.LongTextNarrowScreen} />

## 11. Code

```tsx
<PageHeader
  title="Repositories"
  description="Sources DirectiveBench reads skills, instructions and rules from."
  actions={<Button>Register</Button>}
/>
```

## 12. Do and don't

| Do                                | Don't                              |
| --------------------------------- | ---------------------------------- |
| One PageHeader per page           | A bare `<h1>` with its own classes |
| The main page action in `actions` | Five buttons in `actions`          |

## 13. Related

`PlannedSection`, `Card`, the Detail view pattern.
