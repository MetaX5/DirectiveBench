# What is missing

What this documentation covers, what it does not, and why. Kept current by SPEC-122.

## Done

- Foundations: colour (with measured contrast in both themes), typography, spacing and layout,
  shape and depth, motion, icons, themes.
- Primitives: Button, Badge, Card, Input, Textarea, NativeSelect, Table, Pre, each with 13
  sections and a state matrix.
- Product: PageHeader, Nav, ThemeToggle, EmptyState, NotInitialized, PlannedSection,
  StatusBadge, JobStatusBadge, MockBadge, NotSandboxedBadge, Markdown.
- Patterns: Form, Filtered list, Detail view, Risky-action confirmation, RED/GREEN result, Job
  progress.
