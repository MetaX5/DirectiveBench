# How to choose

"If… use…" for the pairs that exist or are planned. **Missing** marks a component that is not
built; see "What is missing" before you improvise one.

## Actions and navigation

| If you need                                   | Use                                                      | Example                     |
| --------------------------------------------- | -------------------------------------------------------- | --------------------------- |
| To do something on this page                  | `Button`                                                 | Register, Run, Cancel       |
| To go to another page                         | A link (`next/link`)                                     | An artifact name in a table |
| A page's main next step that leaves the page  | `<Button asChild><Link>`                                 | "Open results"              |
| The one main action of a section              | `Button` `default`                                       | Register                    |
| A second action, or one per table row         | `Button` `outline`, `size="sm"` in rows                  | Filter, Scan                |
| An action that overrides a warning or deletes | `Button` `destructive`                                   | Register anyway             |
| An action inside dense chrome                 | `Button` `ghost`, `size="icon"`                          | ThemeToggle                 |
| Views of one page                             | Links with `aria-current` today; Tabs is **missing**     | Artifact tabs               |
| A confirmation that must block the page       | Dialog, **missing**; use the inline Risky-action pattern | Register anyway             |

## Showing status

| If you need                             | Use                                                               | Example                          |
| --------------------------------------- | ----------------------------------------------------------------- | -------------------------------- |
| A run's outcome                         | `StatusBadge`                                                     | Regression                       |
| A job's queue state                     | `JobStatusBadge`                                                  | running                          |
| That a result comes from the mock agent | `MockBadge`, always                                               | Mock agent: not an AI evaluation |
| That commands run without isolation     | `NotSandboxedBadge`                                               | Not sandboxed                    |
| A property or a type                    | `Badge` `outline`                                                 | `skill`, `v3`                    |
| A user label (category)                 | `Badge` `secondary`                                               | security                         |
| Something planned in a working page     | `Badge` `muted` "Planned: not implemented: …"                     | /repositories                    |
| A message that needs reading            | Text with `role="status"` or `role="alert"`; Alert is **missing** | The path check                   |
| A short-lived confirmation              | A `role="status"` line; Toast is **missing**                      | Registered                       |
| Progress                                | Words in a `role="status"` line; no spinner (P11)                 | 18 of 40 files                   |

## Input

| If you need                      | Use                                    | Example              |
| -------------------------------- | -------------------------------------- | -------------------- |
| A short free text                | `Input` with a visible label           | Path or GitHub URL   |
| Several lines                    | `Textarea` with a visible label        | Notes on an artifact |
| One value from up to about 15    | `NativeSelect`, "All" first in filters | Type filter          |
| One value from many, with search | Combobox, **missing**                  | Assign a category    |
| Yes or no, or several values     | Checkbox, **missing**                  | Bulk assign          |

## Layout and content

| If you need                | Use                                                | Example                 |
| -------------------------- | -------------------------------------------------- | ----------------------- |
| A page title               | `PageHeader`                                       | Repositories            |
| A section                  | `Card` with `CardTitle`                            | Register a repository   |
| Rows to compare            | `Table`                                            | Artifacts               |
| Facts about one item       | `dl` by hand today; DescriptionList is **missing** | Overview of an artifact |
| Raw data                   | `Pre`                                              | Run trace               |
| Rendered artifact Markdown | `Markdown`                                         | SKILL.md                |
| Nothing to show            | `EmptyState`                                       | No runs yet             |
| A page that is not built   | `PlannedSection`                                   | Benchmark Builder       |
| Many pages of rows         | Pagination, **missing** (SPEC-113)                 | Results                 |
