# Parameters in force

Shape, density and state parameters shared by the primitives, as the components implement
them on 2026-10-28. Each has a source. "P1" is the shadcn preset Lyra `b3Rq8QfWi` (SPEC-119
AC-1); its values live in the generated `components/ui` files.

## Frozen previews

Hover, focus and pressed cannot be held while reading a page, so the state matrices freeze them
with `data-preview-state="hover"`, `"focus"` or `"pressed"`. Only the Storybook CSS
(`.storybook/states.css`) reads that attribute; the app never sets it.
