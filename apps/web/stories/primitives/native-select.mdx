# NativeSelect

`import { NativeSelect, NativeSelectOption } from '@/components/ui/native-select'`

## 1. Purpose

Choosing one value from a short, known list, with the browser's own select.

## 2. When to use

- Filters on `/artifacts`: Repository, Type, Category, each with "All" first.

## 3. When not to use

| Situation                          | Use instead                                             |
| ---------------------------------- | ------------------------------------------------------- |
| A free text value                  | `Input`                                                 |
| Many options that need search      | A Combobox, on "What is missing" (SPEC-109, categories) |
| Two to four options always visible | A radio group, on "What is missing"                     |
| Choosing several values            | Checkboxes, on "What is missing"                        |

## 4. Anatomy

A wrapper (`data-slot="native-select-wrapper"`) with the `<select>` and a decorative chevron.
Options are `NativeSelectOption`; groups are `NativeSelectOptGroup` (available, unused, P3).

<Canvas of={SelectStories.WithGroups} />

## 5. Variants

One look; `size="sm"` exists in the type but the select keeps the 32px height. The select
stays native: options use the system Canvas and CanvasText colours. Source: SPEC-119 FR-3,
tokeny.md decision 12.

## 6. States

<Canvas of={SelectStories.States} sourceState="none" />

Hover changes the fill in the dark theme only. Focus, disabled and invalid work as on
`Input`. There is no loading state: options are rendered on the server.

## 7. Accessibility

- Name: a visible `<label>` around it, as on `Input`.
- Keyboard: native. Arrow keys change the value; on most systems Space or Alt+Down opens the
  list.
- The chevron is `aria-hidden` and reaches 3:1 (tokeny.md U08).
- A screen reader announces "Type, combo box, All".

## 8. Content

- The first option is the neutral value, "All", when the select filters.
- Outside a filter there is no placeholder option ("Choose a suite…"): the first real value is
  selected, and the visible label says what is chosen. A select whose list is empty is not
  rendered; a sentence says why ("Every benchmark suite is assigned."). Source: issue 64,
  Do and don't below.
- Option text is the value's own name (`skill`, `rule`), not a sentence.

## 9. Responsiveness

The select is as wide as its longest option (`w-fit`); pass `className="w-full"` when it must
fit a narrow column, as below.

## 12. Do and don't

| Do                                           | Don't                                          |
| -------------------------------------------- | ---------------------------------------------- |
| `NativeSelect` with "All" first for a filter | A custom dropdown built from `div`s            |
| A visible label                              | The first option as the label ("Choose type…") |
| `<NativeSelect>`                             | A raw `<select>` (ESLint fails, SPEC-121)      |
