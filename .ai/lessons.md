# Lessons

Durable findings, conclusions and improvements recorded by humans and AI agents — for example
after fixing a bug, discovering a tooling constraint or learning how this repository behaves.
This is the project's long-term memory. **Read it before significant work** (see `AGENTS.md`).

## How to record a lesson

1. Check this list first; update an existing lesson instead of adding a near-duplicate.
2. Copy [`templates/lesson.template.md`](templates/lesson.template.md) to
   `lessons/YYYY-MM-DD-<slug>.md` (date the lesson was learned).
3. Add a one-line entry below, newest first: `- [date] **Rule or fact** — one sentence. → link`.
4. If a lesson becomes wrong, correct or delete it (and its entry) in the same change.

Record a lesson whenever you fix a non-obvious bug, hit a misleading error, find a tooling or
platform constraint, or learn something a future agent would otherwise rediscover the hard way.
Do not record secrets, personal data or information that is already obvious from the code.

- [2026-10-20] **Never probe for a free name with one query per candidate inside a write transaction** — `freeSlug` restarted at `base` for each new artifact, so 3,000 same-named skills cost 4.5 million queries under `BEGIN IMMEDIATE`; read the occupied slugs once per base and allocate from a set shared by all bases (a BINARY range, not `LIKE`), and count statements in a test with thousands of items. → [lessons/2026-10-20-no-query-per-candidate-in-a-write-transaction.md](lessons/2026-10-20-no-query-per-candidate-in-a-write-transaction.md)

- [2026-10-19] **Parsed YAML is not JSON — check it before it reaches a JSON column** — a self-referring alias in frontmatter became a circular object that threw inside the single scan transaction and failed every scan; reject non-JSON values (cycles, `.inf`/`.nan`, `!!binary`/`!!set`/`!!omap`/`!!timestamp`) at the parser as invalid frontmatter, pin `maxAliasCount`, and name the failing item when a per-item write fails. → [lessons/2026-10-19-parsed-yaml-is-not-json.md](lessons/2026-10-19-parsed-yaml-is-not-json.md)
