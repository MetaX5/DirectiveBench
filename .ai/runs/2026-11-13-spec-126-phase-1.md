## Decisions

- The approved F1 to F18 were recorded in SPEC-126 §11.3 first (commit `4891608`); UD-1, UD-6,
  §11.2, FR-126-10 and FR-126-21 were corrected to match.
- A third index, `artifact_occurrences_artifact_idx`, was added to migration 0006 (NFR-126-02
  updated): rule 3's "only local occurrences" check and the FR-126-07 read look occurrences up by
  artifact inside the write transaction, and no index led there.
- Linkability is read from the stored `SKILL.md` content (its frontmatter `name`), never from the
  caller's parsed metadata, so equal hashes always mean equal linkability.
- FR-126-07 reads in two statements per batch (occurrences with version numbers, then only the
  chosen versions' files) to avoid loading every version's content; the statement-count test
  pins it.
- The source-field refresh skips an occurrence whose path does not classify as its version's
  format (only synthetic test rows) or whose version lacks its primary file: kept, not guessed.
- `versionComparisons` takes no `truncated` flag: ancestors are always older and truncation drops
  the oldest pairs, so the walk can never skip a dropped ancestor for an older loaded one (a first
  draft had the flag; removed as dead logic).
- `FromTableRow` (risky-action story) became the GitHub case so it keeps the SPEC-125 sentence
  truthfully; `FromTableRowLocal` shows F8.
